# 2026-10-22 — clouds

## Goal
Realistic clouds with different density and thickness in different regions.

## What was done
- `CloudClimate`, `CloudClimateGenerator`, `CloudFile` (Gen/Weather), `CloudTextureGenerator` (Gen/Textures), `bake-terrain` writes `clouds.bin`.
- Sky shader: two cloud layers, lit, drifting, region-dependent; `DayNightCycle` feeds the shader and lets overhead cloud dim the sun and grey the light.

## Decisions made
[ADR 0022](../decisions/0022-clouds.md).

## Problems encountered and how they were solved
- The anisotropic streak noise could not use the shared noise (one period for both axes, so it seams); it has its own corner function.
- The biome blend of 1,500 m smears everything together in a 1 km test world; the blend is a parameter.

## Tests added
Climate (wet versus dry, mountains, determinism, sampling, file), noise texture (determinism, tileable, varied channels, streaks along rows, golden).

## Docs added/updated
ADR 0022, devlog, CLI reference, game system doc, glossary, known issue 74, CHANGELOG.

## Open questions / next steps
Cloud shadows on the ground, rain and storms from the same map, a `cloud_cover` biome property, tuning by eye.
